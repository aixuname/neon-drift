# 流光穿梭 · NEON DRIFT

一款面向大众的电脑本地霓虹飞行游戏，由 Python / Pygame 实现。
**普通局 30 秒，满三条命可解锁额外 15 秒隐藏关。** 鼠标或方向键控制飞船，躲开危险障碍，收集金色能量，穿越安全通道。

## 启动

### 从 GitHub 下载后直接玩（Windows 64 位）

1. 点击仓库的 **Code → Download ZIP**，下载完整项目。
2. 将压缩包完整解压到可写的文件夹，保留 `runtime` 和 `assets` 目录。
3. 双击 **开始游戏.bat**，在首页选择难度后点击“启动穿梭”或按空格。

双击 **开始游戏.bat**。已携带隔离的 Python 3.13.9 和 Pygame CE 2.5.8，
无需安装、登录或联网。请保留整个文件夹。

排行榜、姓名、个人设置、错误日志、临时文件和测试截图均不会上传到仓库。
首次运行时，游戏会在自身目录内自动创建所需的本地数据目录。

## 转发便携包

运行 `.\runtime\python\python.exe -B .\tools\build_portable.py`，
即可在 `dist` 生成包含完整运行环境的 ZIP 和 SHA-256 校验文件。
把 ZIP 发给对方；对方完整解压后双击 `开始游戏.bat` 即可，无需单独安装 Python。
包内 `先看我.txt` 面向玩家，`agent.md` 与 `AGENTS.md` 面向后续开发维护。
便携包不包含原使用者的姓名、排行榜、个人设置、日志和缓存。

## 玩法

- 首页选择漫游、疾驰或极限，再选择鼠标或键盘操控。
- 点击“启动穿梭”或按空格，三秒准备后开始计时；准备时间不计入正式 30 秒。
- 鼠标模式：移动鼠标控制飞船；键盘模式：方向键或 WASD 移动。
- 障碍有六类：红晶体簇、漂移椭圆弧门、旋转光刃、等离子脉冲束、机械虹膜环、轨道雷球。
- 危险物与子弹统一使用红紫色，奖励能量保留金色。子弹绘制在角色前方，带深色边缘与白色核心，避免被奶龙遮挡。
- 晶体带有立体切面；弧门和虹膜环采用弧形装甲与流光；光刃和脉冲束带有明亮的能量核心；雷球带有球形核心、机械辐条与轨道环。
- 弧门会移动，光刃会旋转，脉冲束会错位，雷球会漂移；晶体轮廓、圆头能量束与椭圆通道的碰撞判定均匹配实际造型。
- 收集金色菱形能量可得分并为护盾充能；连续收集有额外分数。
- 单击场景或按空格释放护盾。初始护盾已充满，每次保护 2 秒。
- 3 点装甲，碰撞后短暂无敌；护盾可抵挡碰撞。装甲耗尽会提前结束本局。
- 受伤时出现装甲碎片、短促震动和独立的装甲碎裂音效；无敌闪烁时仍保留飞船轮廓，便于持续定位。
- 第 30 秒结束时仍有 3 点装甲，会自动进入 15 秒隐藏航线“超频裂隙”，不会先结算；最后一刻扣血则照常结束。护盾挡住伤害仍可满足满血条件。
- 隐藏关立即提升速度、障碍密度、弹速与射击频率，奶龙使用更强的极限攻击模式；场景转为粉紫配色，倒计时改为隐藏关剩余时间。仅短暂显示解锁动画。
- 进入隐藏关时隧道裂隙展开，普通音乐在 0.65 秒内过渡到独立的超频音乐，飞船使用蓝白长尾焰；暂停、静音、重开和返回首页都会正确处理音乐状态。
- 隐藏关最后 5 秒切换为“终极回旋”：随机攻击退场，三波旋转光刃按固定节奏到达，中心与扇区保留可躲避空间。不会延长本局时间。
- 隐藏关继承生命、护盾、能量与累计得分，清除上一段的残留危险后接续新攻击；通关或生命耗尽后统一输入姓名、保存一次成绩。隐藏关只触发一次。
- 成绩仍归入最初选择的难度，额外航行得分累计计入，存档同时记录是否进入及通关隐藏关。
- 普通障碍的生成间隔略缩短约 5%，小幅增加挑战；奶龙事件仍然错峰出场。
- 30 秒内逐渐加速；在 10 秒和 20 秒附近，场景转入新的配色和氛围。
- 三个难度每局均安排三次不同的奶龙事件；包含双枪奶龙，其他类型随机轮换，事件之间保留至少 3.6 秒休息间隔。漫游 / 疾驰大约在第 5、14、23 秒出场，极限稍早。
- 壮奶龙：锁定出场时玩家附近的位置，从远处冲撞；漫游 / 疾驰每次一只，极限每次两只错开出场，冲撞速度已放缓。
- 普通奶龙：漫游一只，疾驰 / 极限两只，在上下两条路线错开横穿，出场间隔 1.55 秒。
- 吐舌奶龙：前进、短暂停顿、反向、再折返，配合上下摆动制造假动作。
- 双枪奶龙：移动射击，轮换扇形、交叉和放射弹幕；子弹有独立的连续运动和碰撞判定。
- 双枪攻击已削弱：出场后 0.75 秒才首次开火，射击间隔拉长、弹速降低，各类弹幕减少子弹并扩大扇形空隙；隐藏关同步削弱，仍比普通局更强。
- 奶龙加入动作细节：双枪射击后坐力与换弹动作，壮奶龙冲过玩家后刹车，吐舌奶龙转向时眨眼、摆动与变换舌头表情；视觉动作不会改变碰撞轮廓。
- 飞船已缩小约三分之一，实际碰撞半径同步减小；子弹也更细、射击间隔更长，扇形弹幕中间留有空隙。
- 子弹出膛后短暂经过 0.14 秒才产生碰撞，避免贴脸生成时立即扣血。
- 奶龙出场时，弧门与虹膜环的通道会加宽，旋转光刃减少为单条，脉冲束减少为两条，给攻击留出穿行空间。
- 同时只出现一种奶龙攻击；极限只额外叠加双倍能量航线，不再叠加流星群。
- 普通障碍持续移动；奶龙或残留子弹存在时，新障碍生成间隔拉长 65%，保留更多躲避空间。三档速度与障碍密度依次提高。
- 游戏过程中显示得分、时间、装甲和护盾；隐藏关解锁时短暂提示，其余事件不显示说明、危险区域虚线或落点倒计时。
- 每次结束可输入自己的名字，支持中文与英文，最多 12 字。
- 结算显示 S / A / B 评级：S 为隐藏关通关，A 为完成普通 30 秒航线，B 为普通航线中途结束。
- 结算按姓名和初始难度显示首次航行、刷新个人纪录、首次进入隐藏关、隐藏关通关、连续收集等成就；同时显示超过前方分数还需多少分。平分不会重复授予“刷新纪录”。
- 评级与已获得成就随成绩保存；兼容没有这些新字段的历史排行榜。未提交的游戏不会改写排行榜或领取成就。
- 按难度分别保留全部提交成绩，排行榜显示前 10 名；同名多局也分别记录。
- 可暂不保存成绩直接返回。所有游戏记录均保存在项目的 `data` 文件夹中。

## 快捷键

| 操作 | 按键 |
|---|---|
| 首页开始 / 暂停后继续 | 空格 |
| 开启 2 秒护盾 | 空格或鼠标左键 |
| 暂停 / 继续 | Esc |
| 全屏 / 窗口 | F11 |
| 静音 | M（输入名字时正常输入字母） |
| 保存成绩 | Enter |
| 清空名字 | Ctrl+A 或 Ctrl+Backspace |

切换到其他窗口会自动暂停。窗口可以缩放，画面保持比例，鼠标坐标会同步换算。

## 计分

航行距离持续计分；成功躲过一组障碍加 15 分。
每颗能量得 25 分，加上连续收集奖励（每次增加 2 分，最多额外 25 分）。
收集一颗能量增加 20% 护盾充能。碰撞或错过整组能量会中断连续收集。
排行榜按得分、收集数量和提交时间排序，三个难度分别排名。

## 文件位置

- `game.py`：桌面入口、透视隧道、界面、音频与本地排行榜。
- `combat.py`：障碍几何、奶龙攻击、弹幕、连续碰撞和 30 秒规则。
- `combat_render.py`：六类障碍、四种奶龙与子弹的实时显示。
- `flight_rewards.py`：航行评级、成就、个人纪录和排名分差比较。
- `runtime/`：项目内的 Python 和依赖。
- `assets/fonts/`：从本机已有项目复制的中文字体，供本机游戏使用。
- `assets/sounds/`：原创合成电子背景音乐和音效，均可离线播放。
- `assets/mascot/combat/`：按用户四张新参考图生成的统一画风透明角色，来源及提示词见该目录说明。
- `assets/mascot/references/`：用户提供的四张参考图，已复制到项目中保存。
- `tools/make_audio.py`：使用标准库生成原创音乐及音效。
- `tools/verify_game.py` / `tools/verify_combat.py`：玩法、时长、碰撞、存档、素材和密集场景验证。
- `tools/prepare_combat_art.py`：透明图集切片及统一尺寸。
- `tools/archive/`：本机保留的历史代码与验证脚本快照，不随仓库上传。
- `data/scores.json`：正式成绩，首次保存成绩时生成。
- `data/settings.json`：难度、操控、静音和上次姓名。
- `data/error.log`：发生异常时生成的错误信息。
- `previews/`：界面预览与验证数据，测试分数不会写入正式排行榜。
- `temp/`：项目内的临时目录。

启动器和程序均把 TEMP/TMP 指向本目录的 `temp`；游戏运行时不访问网络。
当前本机项目存放于 F 盘；下载到其他目录后，文件位置会自动跟随项目目录，不向 C 盘额外写入游戏文件、缓存或存档。

## 源码运行

```powershell
.\runtime\python\python.exe -B .\game.py
```

验证玩法、隐藏关、碰撞和存档（测试使用独立数据，不修改正式排行榜）：

```powershell
.\runtime\python\python.exe -B .\tools\verify_game.py
```

画面中的隧道、光轨、飞船、障碍、流星和能量由代码实时绘制。
四种奶龙风格角色由内置 imagegen 工具根据本次参考图生成，并在本地以透明 PNG 使用；游戏运行时不调用图像服务。
本项目使用透视投影实现立体运动效果。音乐为原创合成器循环，没有依赖在线音乐服务。
